# 通用维度与共用判据

本文件每次评审都读。类专属维在 `code.md` / `app.md` / `skill.md` / `os.md`，只读所审类。

---

## 一、类信号（判类用）

满 2 条即判；多类同时满足取信号最多者。探针会给前三类计数。

| 类 | 信号 |
|---|---|
| `code` | 源码目录；依赖清单（package.json / requirements.txt / go.mod / pyproject.toml）；构建或测试配置；无部署编排 |
| `app` | Dockerfile 或 compose；常驻服务定义；数据库 schema 或迁移目录；环境变量配置 |
| `skill` | SKILL.md 且含 description；被某 agent 加载 |
| `os` | 同一事实在 ≥2 个文件出现；明文执行契约或流程；有"谁判/谁做"分工；有写入或交接动作 |

`os` 类信号脚本给不出，靠手查：全盘搜同一结论句出现的文件数。

## 二、通用 7 维

### G1 有效性 — 声称解决的问题真解决了

1. 找到入口（main / 路由表 / 首页）→ 走一遍主线。
2. 真实性：mock、硬编码样例、示例数据在真实路径上的占比。
3. 功能缺口：对照同类产品的标准功能清单，缺哪些。
4. 空壳率：有界面无后端、有后端无数据源的模块数。

**合格证据**：`文件:行` 的硬编码值、缺 handler 的路由、返回固定值的函数。

### G2 效率 — 响应、资源、运行成本

1. 静态体积：首屏 JS/CSS 总量（gzip 后）、单文件最大体积、图片格式。
2. 请求模式：循环内 IO、N+1 查询、无索引查询、全表扫、可并行却串行。
3. 渲染：长列表是否虚拟化、无谓重渲染点、阻塞首屏的同步脚本。
4. 运行成本：单次任务 token / 算力 / 外部调用次数（AI 类必查）。
5. 依赖重量：装上但只用一两个函数的库。

**合格证据**：文件字节数（探针给）、`文件:行` 的循环内查询、大库 + 调用点。

### G3 可靠 — 失败模式与恢复

1. 错误处理：裸 except / 空 catch 比例；错误是否被吞。
2. 边界：超时、重试、并发上限、队列满。
3. 状态可见：失败后操作者看到什么；有无错误态。
4. 可观测：日志级别、请求 ID、健康检查端点。
5. 恢复：进程重启后数据一致性；有状态服务是否持久化。

**合格证据**：`文件:行` 的 `except: pass`（扫描给）、无 timeout 的请求（扫描给候选，需人工确认）、缺错误分支的分支语句。

### G4 安全 — 权限、秘密、注入面

1. 秘密：仓库内硬编码的密码/密钥/连接串（含注释与示例文件）。
2. 注入：字符串拼接 SQL、命令拼接、模板注入。
3. 认证授权：未鉴权端点清单；权限检查是否集中。
4. 暴露面：`*` 跨域、调试端点、目录列举、默认口令。
5. 依赖漏洞：能跑就跑审计命令，不能跑记"未验证"。

**合格证据**：扫描命中项 + 人工确认；`文件:行` 的秘密字面量、拼接语句、无鉴权判断的路由。

### G5 结构 — 耦合、边界、理解成本

1. 体积分布：文件行数排序（探针给）；最大文件承担了几种职责。
2. 依赖方向：是否有环；下层是否反向依赖上层。
3. 重复：同一逻辑多处实现。
4. 命名与目录：目录名声称的职责与实际内容是否一致。
5. 配置与代码：可变参数是否外置。

**合格证据**：最大文件行数 + 职责列举、环路路径、重复块的行号对。

### G6 交互 — 层级、密度、一致性、可达性

逐页取证，不得抽样后宣称全覆盖。

1. 层级：首屏第一眼看到什么；主要动作是否在首屏。
2. 密度：表格首屏可视行数或列表首屏条目数；关键信息是否要滚动三屏才见。
3. 一致性：同功能控件是否两种实现（按钮/日期/分页）。
4. 键盘：Tab 顺序、焦点可见、Esc 关闭、Enter 提交。
5. 对比度：正文与背景比值；触控目标尺寸。
6. 三态：空态、加载态、错误态是否都有。
7. 响应式：窄屏是否横向滚动、是否重排。

**合格证据**：页面 DOM 行号、断点与对比度数值的 CSS 行（ui 扫描给分布，人工核对具体页）、缺三态的选择器。

### G7 互操作 — 契约与兼容

1. 字段命名：同一接口内 snake/camel 混用。
2. 时间与单位：时区、格式、单位是否显式。
3. 错误码：是否统一、能否判定含义。
4. 版本：版本策略、破坏性变更记录。
5. 兼容：与上下游既有约定的偏离点。

**合格证据**：两处字段命名的行号对、无时区的时间戳、错误码散落点。

## 三、声明≠实现核查表（`skill` / `os` 必走，唯一维护点）

| 它声明 | 必须看到的实现证据 | 看不到就记 |
|---|---|---|
| 有拦截 | 拦截逻辑 + 拒绝返回 | 声明未落地 |
| 有校验 | 脚本存在且可跑通 | 声明未落地 |
| 唯一真相源 | 全盘副本数 = 1 | 漂移 N 处 |
| 有测试 | 用例可跑、有失败态 | 只有用例文件 |
| 触发准确 | 正例/反例触发实测 | 只有触发词列表 |
