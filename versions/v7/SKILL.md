# 他山

**拿外部现实照对象现实，只报差距。不实施、不估成本、不采信自述。**

---

## §1 铁律（违反即整份作废重跑）

1. **唯一输入是一个路径**。会话里已存在的入口文件、项目说明、交接记录，一律**不采信为证据**——它们可能出现在上下文中，但不得支撑任何结论。
2. **自述不算证据**。README、注释、文档里的声称只作背景；结论只认代码、配置、脚本产出、实测。
3. **不与对象共用机制术语**。对象的家法词（组织名、体系名、卡片/回执/编号之类）不进报告；需指认时用客观描述：校验、拦截、预检、写入、交接。
4. **不留历史**。不主动读上一次他山报告；同一会话内已评过同一对象时，报告头写"记忆残留：本会话第 N 轮"。
5. **不估工作量**。只给差距与参照，成本与排期由执行方算。

**自评不免流程**：对象是自己或自己产的件时照常走全流程，报告头追加"自评局限：评审者与对象同源"。

## §2 S0 路由（唯一停点）

### 2.1 判类并取证据

先跑探针，用信号计数判类（满 2 条即判，多类取信号最多者）。

```bash
bash "${TA_SHAN_DIR:-$HOME/.agents/skills/他山}/scripts/run.sh" <目标目录>
```

产物：`<目标目录>/评审/evidence/{probe,scan,ui}.json`；路径不可写时脚本退到临时目录。

信号定义见 `dims/common.md` §一。识别只看物理事实，不认自称。

### 2.2 选维（每次 1-2 维，禁止全维扫描）

| 类 | 专属维 | 该类取证文件 |
|---|---|---|
| `code` | A1 数据流与分层 ｜ A2 测试与校验 | `dims/code.md` |
| `app` | B1 部署与运维 ｜ B2 数据与口径 | `dims/app.md` |
| `skill` | C1 触发精度 ｜ C2 载荷与冲突 | `dims/skill.md` |
| `os` | D1 真相源唯一 ｜ D2 闭环与分工 | `dims/os.md` |

通用 7 维（G1–G7）始终在 `dims/common.md`，与类文件一起读；其余类文件**不读**。

### 2.3 无人值守默认

无人在场时不问，按下列顺序取第一个成立的：

1. 有 `skill` 信号（存在 SKILL.md）→ 判 `skill`，维取 C2 载荷与冲突。**强特征优先于源码计数**。
2. 某类信号 ≥2 → 取该类，维取 G1 有效性。
3. 全为 markdown 且探针报“跨文件重复行 ≥3” → 判 `os`，维取 D1 真相源唯一。
4. 其余 → 判 `code`，维取 G5 结构。

报告头写"已采用默认：类=… 维=… 依据=…"。

**只在两种情形停下问人**：路径不可读；探针与人工都无法判定对象是什么。

### 2.4 报范围

一句话说清：审什么、不审什么、需要对方提供的参照（如"三到五个同类成品"）。

## §3 S1 取证（只读）

1. 跑 `scripts/run.sh`，读 `evidence-*.json`；脚本命中一律标“启发式，需确认”。
2. 按选定维**只读该维小节**（`dims/common.md` 或 `dims/<类>.md` 内按标题定位），不读其余维。
3. 建**现实清单**：事实 + `文件:行` 或 `文件#L行`。此后只认清单。

**复跑（D2）**：修后用 `python scripts/verify.py <目标目录>` 取同一组量化值，按上轮建议表的「验后值」逐条比对，不重写全报告。

**取证纪律**：每维至少 5 条事实才下"健康/不健康"判断；不足 5 条只写"证据不足"。盲区进报告第 5 节，不得用推断填坑。

---

## §4 S2 取外部标尺

按 `refs/bench.md` 的「参照源路由」搜 3-5 条，再取标尺表对照。

每条记 **来源 + 内容年份 + 口径 + 结果 + 依据级 + 一句为何可比**。

- **内容年份**指资料本身的年份，不是今天；缺失则标 `[年份不明]` 并降一级依据。
- **口径**必须写清数值的度量对象（gzip 还是原始、JS 还是全部资源、第几百分位）。口径缺失的数值不得使用。
- **依据级** A 实证 / B 规范 / C 惯例 / D 偏好；D 级不进主表。

**判据不看新旧，看两件事**：结果追不追得到？依据属于哪一级？

**可比性三问**：做的是一类事吗？规模差几倍？结论有实现细节支撑吗？任一答不出即弃用。同类做法 ≠ 营销话术：宣传页、榜单、厂商自评不采。

## §5 S3 对照（强制句式）

> 当【触发条件】时，当前【现实清单事实 · `文件:行`】，参照【来源】的【度量】，差距【可判定差值】。结果：【六类之一】。

写不出这句 → **删掉这条**，不写推测、不写“感觉”。宁少不糊。

**结果六类**：找不到 / 看不懂 / 会做错 / 等太久 / 用不了 / 不敢信。落不进任何一类的，不是差距，是审美偏好——移入“另一种选择”。

## §6 S4 分级

| 影响面 | 判据 |
|---|---|
| 页级 | 单页/单模块内可见 |
| 系统级 | 跨模块或影响全部产出 |
| 架构级 | 换掉或重构才解决 |

| 偏离度 | 判据 |
|---|---|
| 违背硬标准 | 对规范条文确属违规 |
| 落后通行做法 | 标杆普遍已做、此处未做 |
| 另一种选择 | 双方都合理；标"非缺陷"，不占主表 |

**架构级 × 违背硬标准** 必写。排序按影响面 × 偏离度，同级按证据确定度。

## §7 S5 自检（写进报告末节）

- [ ] 报告未使用对象家法术语
- [ ] 未引用任何自我介绍类文件作依据
- [ ] 每条差距有 `文件:行` 或来源
- [ ] 每条差距标了结果类型（六类之一）
- [ ] 无工作量估算
- [ ] 无历史报告引用；有记忆残留已注明
- [ ] 盲区已列

任一项不过 → 重跑该步，不整篇糊过去。

## §8 S6 出报告

报告与对象**不同置**（否则下一轮评审会读到自己）。取第一个可写的：

1. `<对象父目录>/评审-<对象名>/他山-<维度>-<YYYYMMDD>.md`
2. `<对象>/评审/…`（退路，头注“退路落盘，下轮须排除”）
3. 不落盘，直接输出到对话，头注“未落盘：原因”

模板与写作口径见 `refs/report.md`。原文独立成文，事后不改一字；人要批注，批注写在自己文件里。

## §9 脚本与定时

| 脚本 | 作用 | 输出 |
|---|---|---|
| `scripts/probe.py` | 规模、体积分布、类信号 | `evidence-probe.json` |
| `scripts/scan.py` | 秘密字面量、危险模式（启发式） | `evidence-scan.json` |
| `scripts/ui.py` | 断点、颜色/字号分布、可达性启发式 | `evidence-ui.json` |
| `scripts/verify.py` | 复验量化值（字号/颜色/断点/loading/按钮/标签），D1-D2 同口径相减 | 终端或 JSON |
| `scripts/run.sh` | 一键跑三者，并校验输出可解析 | `评审/evidence/` |
| `schedule/tick.sh` | 定时批量取证（**唯一会写对象目录的脚本**） | 各对象 `评审/evidence/` + `PENDING.md` |

**边界**：脚本只取形态证据，不下结论；判断、分级、外部对照仍由评审者完成。

### 脚本失败降级表

| 失败 | 替代动作 |
|---|---|
| 探针跑不起 | 人工量取：`find . -type f | wc -l`、`du -sb .`、`ls -S` 取前 10 |
| 扫描跑不起 | 该维记"未取证"，报告第 5 节写明，不得省略成"未发现" |
| 界面跑不起 | 交互维退化为直接读 HTML/CSS 抽样 |
| 三者全失败 | 只出"证据不足"结论，不出差距表 |

### 定时与消费闭环

见 `schedule/README.md`。定时只做取证与提醒，判断需人或有 agent 在场时执行。

**消费约定**：评审某对象前先看 `<对象>/评审/PENDING.md`，有则优先照其建议维度审；`tick.sh` 结束时打印待评审条数。

## §10 自进化（每轮评审后必做）

改动不等于进化。没有记分、比较与回滚，就只是改。

```bash
python "$TA_SHAN_DIR/scripts/evolve.py" record \
  --found N --new N --carried N --recur N --fixed N --lines N
python "$TA_SHAN_DIR/scripts/evolve.py" fitness
```

```
F = 0.4×修复率 + 0.3×(1−复发率) − 0.2×新增率 − 0.1×成本超限
修复率 = fixed/上轮条数；复发率 = recur/本轮条数
新增率 = min(1.5, new/上轮条数)，首轮记 0
成本超限 = max(0, 必读行数/320 − 1)
```

`fitness` 直接给判定：未降 → 保留；降 1 轮 → `rollback --tag <上一版>`；连续 2 轮降 → 停手等人。

**边界**：F 只度量结构健康，不证明有效性。有效性只能由外部对象证：同维度首跑 D1、修后复跑 D2，收敛率 =(D1−D2)/D1。没有 D 的报告不得声称“变好了”。

复跑口径：`verify.py` 取量化值 → 按 D1 建议表的「验后值」逐条判 → 只记差异，不重写报告。

## §11 与外部的关系

报告出去后由人决定采纳与否。**不接受的追加输入**：对象的自我标准、内部体系说明、"顺手看看我们的规范"——那会毁掉独立性。
