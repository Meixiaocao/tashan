# 版本快照

## 用途

`rollback --tag vN` 的还原源。快照是完整文件副本，不含 `versions/`、`评审/`、`.git`。

## 保留策略

**只留里程碑，其余由 git 历史承担。**

| 保留 | 理由 |
|---|---|
| 最近 1 个 | 回滚用 |
| 标为 milestone 的 | 结构大幅变动前的状态 |

判定 standard：仓库已推送到远端，每个提交都是完整历史，快照只在"需要不经 git 直接还原文件"时有用，
因此不必保留每一版。

## 清理

```bash
ls versions/ | grep '^v' | head -n -1   # 除最新外全部
```

删除前确认对应版本已提交到 git。
