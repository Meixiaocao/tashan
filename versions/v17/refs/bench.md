# 标尺与依据

判据不是"新不新"，是**结果追不追得到、依据强不强**。年份只用来判断依据是否已失效，不作淘汰理由。

---

## 一、结果六类（每条差距必须落一类）

| 结果 | 用户表现 | 可测形态 |
|---|---|---|
| 找不到 | 翻半天没入口 | 点击路径长度、首屏可见性 |
| 看不懂 | 读不出含义 | 字号 / 对比度 / 术语一致性 |
| 会做错 | 误操作 | 缺确认、缺校验、按钮默认行为 |
| 等太久 | 等待无反馈 | 传输字节、状态缺失 |
| 用不了 | 键盘 / 读屏 / 低视力不可用 | 焦点、标签、语义角色 |
| 不敢信 | 不知是真是假 | 演示与真实无标识、状态不可见 |

落不进任何一类的，不是差距，是审美偏好。

---

## 二、依据四级

| 级 | 含义 | 是否进主表 |
|---|---|---|
| A 实证 | 可复现的测量或研究结论 | 进 |
| B 规范 | 标准条文（WCAG / ISO / RFC / ARIA） | 进 |
| C 惯例 | 主流产品一致做法 | 进，须标"惯例" |
| D 偏好 | 无依据，仅个人或单一产品主张 | 不进，写入"另一种选择" |

## 三、标尺表

| 标尺 | 值 | 口径（必须写清） | 结果 | 依据 | 年份 / 版本 |
|---|---|---|---|---|---|
| Core Web Vitals | LCP ≤ 2.5s ｜ INP ≤ 200ms ｜ CLS ≤ 0.1 | 真实用户第 75 百分位 | 等太久 | B | 2024（INP 取代 FID） |
| 主包 JS | gzip 后 ≤ 200 KB | **gzip 后主包 JS 字节**，不含异步分包 | 等太久 | C | 2026 共识；预算应取自自身基线，无通用分数 |
| 未压缩 JS 告警线 | 244 KiB | 未压缩单入口 | 等太久 | C | webpack 默认值 |
| 长列表 | 可视节点 > 200 行建议虚拟化 | 首屏渲染节点数 | 等太久 | C | — |
| 对比度 | 正文 ≥ 4.5:1，大文本 ≥ 3:1 | 计算值（前景/背景） | 看不懂 · 用不了 | B | WCAG 2.2 SC 1.4.3（2023） |
| 触控目标 | ≥ 24×24 CSS px | 元素边框盒 | 用不了 | B | WCAG 2.2 SC 2.5.8 |
| 焦点可见 | 键盘遍历必须有可见指示 | Tab 走查 | 用不了 | B | WCAG 2.2 SC 2.4.7 / 2.4.11 |
| 表单标签 | 每个输入有可关联标签，占位符不算 | DOM 关联关系 | 用不了 | B | WCAG 2.2 SC 3.3.2 |
| 正文字号 | 16 px 常用，默认不小于 12 px | 计算 px（1rem=16 基准） | 看不懂 | C | WCAG **无**最小字号条款，此为惯例 |
| 中后台表格行高 | 40–48 px | 行高 | 找不到 | D→仅作参考，不进主表 | — |
| 可用性启发式 | 10 条原则 | 原则，不给数字 | 六类均有 | A | 1994 归纳，原则稳定 |
| 产品九特性 | 功能适合 / 性能 / 兼容 / 交互 / 可靠 / 安全 / 可维护 / 可移植 | 特性名，不给阈值 | — | B | ISO/IEC 25010:2023 |
| 场景六要素 | 刺激源-刺激-环境-制品-响应-度量 | 方法 | — | B | ATAM |
| 交付四指标 | 前置时间 / 部署频率 / 失败率 / 恢复时长 | 团队自身纵向比较 | — | A | DORA，持续更新 |
| 技能四评估维 | 安全 / 质量增益 / 触发可靠 / 成本效率 | — | — | C | 2025–2026 实践 |
| 文档审计维 | 覆盖 / 可查找 / 准确 / 时新 / 结构 / 可及 | — | 找不到 | C | — |

**上表分两种性质**：依据为 B 的是条款引用，版本号即时效锚，按新版更新；依据为 C / D 的是**采样惯例，不是阈值**——
每次评审按 `refs/standard.md` 重新检索确认，不要直接沿用本表的数字。

**阈值必须带口径**。同一个数，口径不同结论就相反：
"188 KB" 是未压缩单文件，"188 KB gzip 后"是另一回事。口径缺失的数值不得使用。

## 四、参照记录格式

```
来源：<URL 或 文档名+版本>
内容年份：<YYYY 或 版本号，不是抓取日期>
口径：<数值的度量对象与单位>
结果：<六类之一>
依据：<A/B/C/D>
可比：<一句话，说明为什么这个对象能拿来对照>
```

缺"口径"或"可比"的，弃用。缺"内容年份"的，标 `[年份不明]` 并降一级依据。

## 五、参照源路由

每类至少 3 条，优先取有实现细节的源。

| 类 | 搜什么 | 可比的条件 |
|---|---|---|
| `code` | 同域开源项目的结构与选型说明；框架官方实践；领域权威清单 | 规模同量级、问题域同型、有代码可看 |
| `app` | 同类工具的公开文档与操作说明；部署运维实践 | 使用者角色相同，非消费级产品 |
| `skill` | 技能市场同类件结构；官方编写指南；技能评估研究 | 触发场景重叠或任务同型 |
| `os` | 工程效能框架；知识审计与单一真相源审计方法 | 团队规模同量级，不搬大厂流程 |

**可比性三问**：做的是一类事吗？规模差几倍？结论有实现细节支撑吗？任一答不出即弃用。
同类做法 ≠ 营销话术：宣传页、榜单、厂商自评不采。
