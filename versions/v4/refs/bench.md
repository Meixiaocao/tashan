# 外部标尺

引用时写清条款或数值，不写"业界普遍认为"。数值随版本变，采用时记抓取日期。

| 类别 | 标尺 | 具体值 / 条款 |
|---|---|---|
| 性能 | Core Web Vitals 良好阈值 | LCP ≤ 2.5s ｜ INP ≤ 200ms ｜ CLS ≤ 0.1（第 75 百分位） |
| 性能 | 首屏 JS 预算 | 约 170KB gzip 为常见上限 |
| 渲染 | 长列表 | 可视节点 > 200 行建议虚拟化 |
| 交互 | 正文对比度 | ≥ 4.5:1（大文本 ≥ 3:1）｜ WCAG 2.2 SC 1.4.3 |
| 交互 | 触控目标 | ≥ 24×24 CSS px；移动端惯例 44×44 ｜ SC 2.5.8 |
| 交互 | 焦点可见 | 键盘焦点必须有可见指示 ｜ SC 2.4.7 / 2.4.11 |
| 交互 | 表单标签 | 每个输入有可关联标签，占位符不算 ｜ SC 3.3.2 |
| 交互 | 可用性启发式 | 状态可见 / 贴合现实 / 可控 / 一致 / 防错 / 识别优于回忆 / 效率 / 简洁 / 错误恢复 / 帮助 |
| 交互 | 中后台表格密度 | 行高 40–48px，首屏 15–20 行 |
| 质量 | 产品九特性 | 功能适合 / 性能效率 / 兼容 / 交互可用 / 可靠 / 安全 / 可维护 / 可移植（ISO/IEC 25010:2023） |
| 架构 | 场景六要素 | 刺激源-刺激-环境-制品-响应-度量（ATAM） |
| 交付 | 四项核心指标 | 变更前置时间 / 部署频率 / 变更失败率 / 恢复时长（DORA） |
| 技能 | 四评估维 | 安全 / 质量增益 / 触发可靠 / 成本效率 |
| 技能 | 载荷分层 | 元数据常驻；正文激活时载入，建议 <5000 tokens / <500 行；资源按需 |
| 文档 | 审计维度 | 覆盖 / 可查找 / 准确 / 时新 / 结构 / 可及 |
| 文档 | 可信判据 | 标了"唯一真相源"不等于可信，须数副本 |

## 参照源路由

每类至少 3 条，优先取有实现细节的源。

| 类 | 搜什么 | 可比的条件 |
|---|---|---|
| `code` | 同域开源项目的结构与选型说明；框架官方实践；领域权威清单 | 规模同量级、问题域同型、有代码可看 |
| `app` | 同类工具的公开文档与操作说明；部署运维实践 | 使用者角色相同，非消费级产品 |
| `skill` | 技能市场同类件结构；官方编写指南；技能评估研究 | 触发场景重叠或任务同型 |
| `os` | 工程效能框架；知识审计与单一真相源审计方法 | 团队规模同量级，不搬大厂流程 |

## 参照记录格式

```
来源：<URL 或 文档名+版本>
抓取：<YYYY-MM-DD>
可比：<一句话，说明为什么这个对象可以拿来对照>
度量：<具体数值或条款号，用于差距计算>
```

缺"可比"的参照弃用。
