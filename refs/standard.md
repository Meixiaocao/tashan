# 找标准（流程，不是清单）

技能里存标准，就是存过期物。可复用的是**获取方法**：每次现搜当下的参照，验完可比性再用。

七维、十个子系统、某某 KB 预算——这些东西会变。而"怎么找、怎么验、怎么记"不会变。

---

## 一、为什么单列一层

| 若把标准写进技能 | 后果 |
|---|---|
| 用现成的清单逐个对照 | 评审者停止搜索，只做勾选 |
| 清单半年后过期 | 拿旧尺子量新东西，还没人察觉 |
| 清单来自一家之言 | 变成"某个作者的偏好"，不是外部锚点 |

**判据只看一件事：这个标准能不能追到用户结果。** 追得到才用，追不到就换。

---

## 二、五步

### 1 定结果目标

这次评审要改善六类结果中的哪一类。写不出就停——没有结果目标的评审只是清单罗列。

一次 1–2 类，多了就散。

### 2 搜当下参照

搜索构造（三路并进，不要只搜一种）：

```
<对象类型> <问题域> best practice <当前年份>
<标准组织> <标准名> latest version
<同类开源项目> <主题> 实现
```

必须拿到三种之一以上：

| 类型 | 例 | 优先级 |
|---|---|---|
| 有实现细节的同类对象 | 源码研究、架构对照、运维清单 | 高 |
| 官方规范最新版 | WCAG 2.2、ISO 25010:2023、RFC | 高 |
| 领域实证研究 | 可复现的测量或实验 | 高 |
| 榜单 / 营销页 / 厂商自评 | — | **不用** |

### 3 验可比性（四问，任一否即弃）

1. **做的是一类事吗**？消费级产品的做法不一定适用于内部工具。
2. **规模差几个量级**？十人团队搬大厂流程会压死。
3. **有实现细节吗**？能说出怎么做的才叫参照，说"我们重视质量"的不是。
4. **结论能追到结果吗**？追不到就是观点，不是标准。

### 4 查环境约束

标准是"在什么条件下算好"。同一件事在不同约束下答案相反：

| 约束 | 改变什么 |
|---|---|
| 单机 / 多机 | 令牌方案、共享状态、部署路径 |
| 磁盘与内存余量 | 能不能缓存、能不能拆包、能不能上压缩 |
| 运行时版本下限 | 能用哪些语法与库 |
| 不可动接口 | 哪些重构从一开始就不成立 |
| 时间窗与人力 | 哪些改进属于"现在做"，哪些属于"以后再说" |

约束表在 `共享方法/环境知识/资源台账.md`；缺项标"待填"，不替决策者假设。

### 5 对照与评价

回到 `refs/bench.md` 的结果六类与依据四级，出场景句式，再做 `refs/tradeoff.md` 的支配判定。

## 三、记录格式（每条参照必填）

| 字段 | 要求 |
|---|---|
| 来源 | URL 或 文档名 + 版本号 |
| 内容年份 | 资料本身的年份，**不是今天**；缺失标 `[年份不明]` 并降一级依据 |
| 口径 | 数值的度量对象（gzip 前后、JS 还是全部资源、第几百分位） |
| 结果 | 六类之一 |
| 依据 | A 实证 / B 规范 / C 惯例 / D 偏好 |
| 可比 | 一句话：为什么这个对象能拿来对照 |

**缺"口径"或"可比"的参照，弃用。**

---

## 四、两类标准的处置

| 性质 | 例 | 处置 |
|---|---|---|
| **规范类**（有版本号） | WCAG 2.2 SC 1.4.3、ISO 25010:2023、RFC 7231 | 可长期引用；版本号即时效锚，新版本发布时更新 |
| **经验值类**（数值阈值） | "首屏 JS ≤ N KB"、"行高 40–48 px" | 每次现搜；引用时必写年份与口径 |
| **领域清单类**（该有哪些组件） | agent 的系统构成、微服务的分层 | **不固化**；每次搜，搜到后按四问验 |

`refs/samples/` 里存的是某一次检索的采样，标了日期与来源。**它是示例，不是标准**；评审时须重新检索。

---

## 五、反模式

| 反模式 | 为什么错 |
|---|---|
| 用记忆里的数字 | 记不住口径，也记不住年份 |
| 抄别人的清单当标尺 | 那是别人的结论，不是你的证据 |
| 只看一家厂商文档 | 厂商文档描述的是它的产品，不是领域共识 |
| 把"业界普遍认为"当依据 | 无法验证，等于没依据 |
| 搜到一个就停 | 单点来源无法判断它是常态还是特例 |
| 标准与对象同源 | 对象自己引用的资料不算外部锚点 |

---

## 六、检索落空怎么办

| 情况 | 处置 |
|---|---|
| 搜不到同类对象 | 报告第 5 节写"缺外部参照"，该维只出事实不出评价 |
| 搜到的都是营销页 | 同上，不降级使用 |
| 只有规范没有实现 | 用规范作 B 级依据，注明"无实现参照" |
| 约束表缺项 | 只出阶段 A（支配型），阶段 B 标"待约束" |

**宁可这轮不出结论，不可用编的参照出结论。**
