# 感知：标准从世界来，不从记忆来

## 不搜条文，搜状态

技能里不存标准。每轮现搜，搜的是**世界当下的样子**。

| 搜什么 | 在哪搜 | 判什么 |
|---|---|---|
| 同类实例怎么做的 | 开源项目同类模块、友商产品文档、公开代码 | 这是活的参照系 |
| 官方最新怎么说 | W3C / RFC / 框架官方文档，带版本号 | 版本号即时效锚 |
| 有人踩过吗 | issue 区、事故复盘、实证研究 | 别人的实践 |
| 这个领域怎么称呼它 | 领域术语 | 说行话，不说外行话 |

判断力来自**看得够多**，不是记得够全。

## 搜之前先问五句

1. **这次要改善什么结果？** 说不出就停止，本轮不出评价。
2. **谁受影响？他现在的体验是什么？**
3. **环境的硬约束是什么？** 部署形态、资源上限、运行时版本、不能动的接口。
4. **有没有同类可比？规模差几级？**
5. **搜到的数，口径是什么？**

## 可比性四问（任一否即弃）

- **一类事吗？** 后台管理界面与面向公众的落地页，判据不同。
- **规模差几级？** 千行与十万行，「该不该拆」的答案相反。
- **有实现细节吗？** 只有截图和营销词的，不算参照。
- **能追到结果吗？** 说「提升了 30%」而不说量的是什么，不能用。

榜单、营销页、无出处的「最佳实践」清单，一律不用。

## 口径纪律

- **阈值必须带口径**。188 KB 未压缩与 188 KB gzip 后是两个世界。
- **口径不明的数值不得使用**。写下「约 3 倍」而不说比什么，等于没写。
- **年份只判依据是否失效，不作淘汰理由**。1994 年的可用性启发式仍有效；2019 年的某个数字可能口径早就错了。

## 搜不到怎么办

写「缺外部参照」，该条只出事实不出评价。

**宁可这轮不出结论，不可用编的参照出结论。** 一条编出来的标准会污染后面所有判断。

## 什么时候该停

搜到第三条独立来源都指向同一结论，就够。继续搜是拖延，不是严谨。

反过来：只搜到一条就下结论，要标「单一来源」。
