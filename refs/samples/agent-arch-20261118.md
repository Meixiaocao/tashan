# 采样：agent 类架构对标（2026-11-18）

> **这是一次检索的采样，不是本技能的标准。**
> 评审任何对象时都须按 `refs/standard.md` 重新检索当下的共识构成；本文只作示例，说明"搜到的对照材料长什么样"。
> 来源：arXiv 2609.00006《Harness Engineering: Anatomy, Architecture, and Evolution of Coding Agents》（对 11 个 coding agent 的源码级研究）、aiarch.dev 分层模型、OpenAI Sandbox 文档、AWS agent reference architecture。

## 采样子系统表

| # | 子系统 | 最小形态（缺了会怎样） | 成熟形态 |
|---|---|---|---|
| 1 | 推理循环 | 一个循环套一个工具；失败即停 | 停止条件、最大步数、失败恢复、可中断 |
| 2 | 上下文管理 | 全量重放，长任务变慢变贵 | 压缩历史、延迟加载工具定义、卸载超大工具返回 |
| 3 | 工具层 | 一个万能入口 | schema 校验、超时、权限分级 |
| 4 | 沙盒 | 直接跑在宿主上 | 隔离执行环境（文件系统 / shell / 快照），或把沙盒当工具而非常驻 |
| 5 | 记忆 | 只有会话内历史 | 短期 / 长期分层，可检索、可写入 |
| 6 | 状态持久化 | 重启即丢 | 断点续跑、崩溃恢复 |
| 7 | 编排 | 单 agent 串行 | 子 agent、任务分解、并发上限 |
| 8 | 可观测 | stdout 日志 | trace：做了什么、看到什么、花了多少、为什么停 |
| 9 | 评估 | 无回归集 | 固定任务集 → 发布门禁 |
| 10 | 审批与边界 | 无 | 人工审批点、凭证作用域、出口策略 |

## 采样内核对比维度

模型支持（单厂商/多 provider/本地）｜上下文效率｜子 agent｜沙盒形态（整会话隔离 vs 工具级）｜状态持久化｜扩展面（MCP / skills / 自定义工具）｜可观测。

## 使用注意

- 上表是 2026-11 的采样。领域演进快，隔半年再看可能已增删项。
- 采样里的"成熟形态"描述的是当时领先实现的做法，不是必须达到的标准。
- 判定"缺"之前仍须走反向搜索词表（见 `dims/arch.md` §五），并核对依赖包。
