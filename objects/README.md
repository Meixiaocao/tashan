# 外部评审台账

技能对外部对象的评审结果记在这里。**这是控制回路的最后一段**：没有它，F 只能证明"评审自己没退步"，不能证明"评审对外部有用"。

## 两条线分开记

| 线 | 在哪 | 答什么 |
|---|---|---|
| 自评线 | `versions/ledger.jsonl` | 技能自己有没有退步（F） |
| 对象线 | `objects/ledger.jsonl` | 建议在对象身上收敛了多少 |

两条都要，不能互相替代。

## 字段

```json
{"date":"YYYY-MM-DD","object":"代号","what":"一句话说清它是什么",
 "d1":0,"d2_valid":0,"converged":0,"fp":0,"partial":0,"note":"..."}
```

| 字段 | 含义 |
|---|---|
| `d1` | 首次评审出的差距条数 |
| `d2_valid` | 复评时确认有效的条数（剔除误报与半误报） |
| `converged` | 复评时已达成验后值的条数 |
| `fp` / `partial` | 外部复核判定为完全误报 / 半误报的条数 |

## 汇总

```bash
python scripts/object_stats.py
```

输出总收敛率与各对象明细。

## 口径

```
收敛率 = Σconverged / Σd2_valid
精确率 = 1 − (Σfp + 0.5×Σpartial) / Σd1
```

**两个数分开报，不相乘、不加权**。收敛率高但精确率低，说明建议有效但噪声多；反过来说明稳但推不动。
